# Ide: KosFinder

## 1. Pengguna

- Mahasiswa atau masyarakat yang sedang mencari tempat kos, Pengguna tidak perlu login untuk melihat daftar kos.
- Pemilik kos yang ingin mempromosikan dan mengelola informasi kos miliknya. Pemilik harus login untuk mengelola kos.

## 2. Masalah

Informasi tempat kos masih tersebar di berbagai media, seperti grup WhatsApp, media sosial, dan informasi dari teman.

Akibatnya:
- Pencari kos kesulitan menemukan informasi kos dalam satu tempat.
- Pencari kos kesulitan membandingkan harga dan fasilitas.
- Informasi harga dan ketersediaan kamar terkadang tidak diperbarui.
- Pemilik kos kesulitan mempublikasikan dan memperbarui informasi kos miliknya.

## 3. Yang Diharapkan Bisa Dilakukan

- Pengguna dapat melihat daftar kos tanpa harus login.
- Pengguna dapat melihat detail kos, termasuk harga, alamat, fasilitas, dan deskripsi.
- Pengguna dapat mencari kos berdasarkan nama atau area.
- Pengguna dapat menyaring kos berdasarkan harga.
- Pemilik kos dapat mendaftar dan login.
- Pemilik kos dapat menambahkan informasi kos miliknya.
- Pemilik kos dapat mengubah dan menghapus informasi kos miliknya sendiri.

## 4. Batasan

- Aplikasi dibuat untuk platform Android menggunakan Flutter.
- Backend menggunakan Supabase untuk database dan autentikasi.
- Versi pertama tidak mencakup pembayaran online, fitur chat, ulasan dan rating, rekomendasi AI, verifikasi identitas pemilik, upload foto, dan peta digital.
- Aplikasi dibuat dengan fitur sesederhana mungkin agar mudah digunakan oleh pencari kos dan pemilik kos.
