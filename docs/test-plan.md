# Test Plan — KosFinder v1

Dokumen rencana pengujian (*test plan*) aplikasi **KosFinder v1** yang mencakup seluruh skenario fungsional berdasarkan *User Stories* dan *Acceptance Criteria* (AC) di `docs/PRD.md`, termasuk skenario positif dan skenario negatif (hasil kosong, tanpa koneksi internet, input tidak valid, dan proteksi hak akses / Row Level Security pemilik lain).

---

## Tabel Rencana Pengujian

| ID | AC Terkait | Langkah Pengujian | Hasil yang Diharapkan | Hasil Nyata | Lulus |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-01** | `US01-AC1` | 1. Buka aplikasi tanpa login akun.<br>2. Perhatikan kartu-kartu kos yang tampil pada halaman Beranda (*HomeScreen*). | Menampilkan daftar kos publik yang memuat nama kos, alamat, jenis kos (Putra/Putri/Campur), harga sewa per bulan, dan badge teks status ketersediaan (Tersedia/Penuh). | | |
| **TC-02** | `US01-AC2` | 1. Pastikan terdapat beberapa data kos dengan waktu pembuatan berbeda di database.<br>2. Buka halaman Beranda aplikasi. | Daftar kos ditampilkan terurut berdasarkan data yang paling baru ditambahkan berada di posisi paling atas (`created_at DESC`). | | |
| **TC-03** | `US01-AC3` | 1. Kondisikan tabel `kos` di database dalam keadaan kosong.<br>2. Buka halaman Beranda aplikasi. | Aplikasi menampilkan pesan informatif "Belum ada kos yang terdaftar" dan ikon ilustrasi (bukan layar kosong atau error putih). | | |
| **TC-04** | `US01-AC4` | 1. Matikan koneksi internet (Airplane mode / disconnect Wi-Fi & data).<br>2. | **TC-05** | `US02-AC1` | 1. Dari halaman Beranda, tap salah satu kartu kos.<br>2. Periksa informasi yang disajikan di halaman `DetailKosScreen`. | Menampilkan 9 informasi lengkap kos secara rinci: (1) Nama kos, (2) Alamat lengkap, (3) Harga per bulan, (4) Jenis kos, (5) Fasilitas (AC, WiFi, kamar mandi dalam, parkir, dapur bersama), (6) Deskripsi kos, (7) Jumlah kamar tersedia, (8) Kontak WhatsApp pemilik, dan (9) Status ketersediaan (Tersedia/Penuh). | | |
| **TC-06** | `US02-AC1` | 1. Pada halaman `DetailKosScreen`, tap tombol "Hubungi via WhatsApp". | Aplikasi memicu `url_launcher` untuk membuka tautan WhatsApp resmi (`https://wa.me/...`) dengan pesan otomatis pembuka ke nomor pemilik. | | |
| **TC-07** | `US02-AC2` | 1. Matikan koneksi internet.<br>2. Navigasikan ke halaman detail kos melalui deep link / ID kos tanpa cache lokal. | Aplikasi menampilkan pesan error ("Gagal memuat detail kos. Silakan periksa koneksi internet Anda.") dan menyediakan tombol "Coba lagi" (bukan layar putih). | | |
| **TC-08** | `US03-AC1` | 1. Masukkan kata kunci nama kos atau area (contoh: "Tembalang" / "Singaraja") pada kolom pencarian di Beranda.<br>2. Tekan tombol Enter / Search pada keyboard virtual. | Daftar kos disaring secara dinamis sehingga hanya menampilkan kos yang nama atau alamatnya mengandung kata kunci tersebut. | | |
| **TC-09** | `US03-AC2` | 1. Masukkan kata kunci acak yang tidak ada di data mana pun (contoh: "xyz987tidakada").<br>2. Tekan tombol Search. | Aplikasi menampilkan pesan "Kos tidak ditemukan" beserta tombol saran untuk mereset/menghapus kata kunci pencarian. | | |
| **TC-10** | `US04-AC1` | 1. Tap ikon Filter Harga di AppBar Beranda.<br>2. Masukkan harga minimum `500000` dan maksimum `1000000`.<br>3. Tap tombol "Terapkan". | Daftar kos pada Beranda hanya menampilkan kos dengan harga sewa per bulan di dalam rentang Rp 500.000 s/d Rp 1.000.000, serta muncul indikator chip filter harga aktif. | | |
| **TC-11** | `US04-AC2` | 1. Buka dialog Filter Harga.<br>2. Masukkan harga minimum `1000000` dan harga maksimum `500000` (min > maks).<br>3. Tap tombol "Terapkan". | Filter ditolak; form menampilkan pesan validasi error "Harga minimum tidak boleh lebih besar dari harga maksimum" dan daftar kos tidak berubah. | | |
| **TC-12** | `US04-AC1` | 1. Buka dialog Filter Harga yang sedang aktif.<br>2. Tap tombol "Reset" atau tap tombol silang pada chip filter harga. | Seluruh filter rentang harga dihapus dan daftar kos kembali menampilkan semua harga seperti semula. | | |
| **TC-13** | `US05-AC1` | 1. Tap ikon Area Pemilik $\rightarrow$ tap "Daftar di sini".<br>2. Masukkan email valid yang belum pernah terdaftar dan password $\ge 8$ karakter.<br>3. Ulangi password di kolom konfirmasi secara cocok $\rightarrow$ tap "Daftar". | Akun baru berhasil dibuat di Supabase Auth, menampilkan SnackBar "Pendaftaran berhasil! Akun pemilik aktif.", dan pengguna langsung dialihkan masuk ke `OwnerDashboardScreen`. | | |
| **TC-14** | `US05-AC1` | 1. Di form registrasi, masukkan password kurang dari 8 karakter (contoh: "12345").<br>2. Tap tombol "Daftar". | Registrasi ditolak; form menampilkan pesan validasi "Password minimal 8 karakter" dan request tidak dikirim ke server. | | |
| **TC-15** | `US05-AC1` | 1. Di form registrasi, masukkan konfirmasi password yang tidak cocok dengan password utama.<br>2. Tap tombol "Daftar". | Registrasi ditolak; form menampilkan pesan validasi "Konfirmasi password tidak cocok". | | |
| **TC-16** | `US05-AC2` | 1. Di form registrasi, masukkan email yang sudah pernah terdaftar sebelumnya dan password valid.<br>2. Tap tombol "Daftar". | Pendaftaran gagal; aplikasi menampilkan SnackBar pesan kesalahan "Email sudah digunakan". | | |
| **TC-17** | `US05-AC3` | 1. Buka halaman Login Pemilik.<br>2. Masukkan email dan password akun terdaftar yang benar.<br>3. Tap tombol "Login". | Autentikasi berhasil; menampilkan SnackBar "Login berhasil! Selamat datang." dan pengguna langsung masuk ke halaman `OwnerDashboardScreen`. | | |
| **TC-18** | `US05-AC4` | 1. Buka halaman Login Pemilik.<br>2. Masukkan email terdaftar namun dengan password yang salah.<br>3. Tap tombol "Login". | Login gagal; aplikasi menampilkan SnackBar pesan kesalahan "Email atau password salah" dan form tetap berada di layar Login. | | |
| **TC-19** | `US05-AC3` | 1. Login sebagai pemilik hingga berada di `OwnerDashboardScreen`.<br>2. Tekan tombol back untuk kembali ke Beranda.<br>3. Tekan kembali ikon "Area Pemilik" di AppBar. | Aplikasi langsung membuka `OwnerDashboardScreen` tanpa memunculkan form login kembali karena sesi login masih aktif (`isAuthenticated == true`). | | |
| **TC-20** | `US05-AC3` | 1. Dari `OwnerDashboardScreen`, tap ikon logout di AppBar.<br>2. Konfirmasi "Keluar" pada dialog yang muncul. | Pengguna berhasil keluar dari sesi; kembali ke `HomeScreen`, dan jika ikon Area Pemilik ditekan akan meminta login ulang. | | |
| **TC-21** | `US06-AC1` | 1. Pada `OwnerDashboardScreen`, tap tombol "+ Tambah Kos".<br>2. Isi lengkap seluruh 8 field wajib: Nama kos, Alamat lengkap, Harga sewa, Jenis kos, Checklist fasilitas (min. 1), Jumlah kamar, Nomor WhatsApp, dan Deskripsi.<br>3. Tap tombol "Simpan Kos". | Data kos baru berhasil tersimpan ke Supabase terikat dengan `owner_id` akun aktif, muncul di daftar kos `OwnerDashboardScreen`, dan langsung tampil pada daftar kos publik di `HomeScreen`. | | |
| **TC-22** | `US06-AC2` | 1. Buka form Tambah Kos.<br>2. Kosongkan salah satu atau seluruh field wajib (misal: tanpa memilih fasilitas atau mengosongkan nama kos).<br>3. Tap tombol "Simpan Kos". | Data tidak disimpan; form menampilkan pesan validasi error di bawah masing-masing field yang belum diisi ("... wajib diisi" / "Pilih minimal satu fasilitas kos"). | | |
| **TC-23** | `US06-AC2` | 1. Pada form Tambah Kos, isi harga sewa atau jumlah kamar dengan nilai negatif atau format non-angka.<br>2. Tap tombol "Simpan Kos". | Form menampilkan pesan validasi "Harga harus berupa angka valid (>= 0)" atau "Jumlah kamar harus angka valid (>= 0)". | | |
| **TC-24** | `US06-AC2` | 1. Pada form Tambah Kos, isi nomor WhatsApp kurang dari 9 digit (contoh: "08123").<br>2. Tap tombol "Simpan Kos". | Form menampilkan pesan validasi "Nomor WhatsApp minimal 9 digit" dan data tidak dikirim. | | |

| **TC-27** | `US07-AC2` | 1. Pada kartu kos di `OwnerDashboardScreen`, tap tombol "Hapus". | Aplikasi menampilkan pop-up dialog konfirmasi: "Apakah Anda yakin ingin menghapus kos...? Tindakan ini tidak dapat dibatalkan." dengan opsi "Batal" dan "Hapus". | | |
| **TC-28** | `US07-AC2` | 1. Pada dialog konfirmasi hapus kos, tap tombol "Batal". | Dialog tertutup, data kos tidak dihapus, dan kos tetap muncul di dashboard serta publik. | | |
| **TC-29** | `US07-AC2` | 1. Pada dialog konfirmasi hapus kos, tap tombol "Hapus". | Kos terhapus secara permanen dari Supabase, muncul SnackBar "Kos ... berhasil dihapus.", kartu kos hilang dari dashboard pemilik, dan tidak lagi tampil di daftar publik `HomeScreen`. | | |
